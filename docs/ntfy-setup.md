# Notification setup (ntfy)

job-alerts publishes notifications to a topic on [ntfy.sh](https://ntfy.sh). The topic name is the only secret - anyone who knows it can publish or read from it, so don't share it and regenerate it on the Profile page if it leaks.

## Receiving notifications

Install the [ntfy app](https://ntfy.sh/#subscribe) (iOS/Android) and subscribe to your topic.

## Changing your topic

Save a new topic on the Profile page - job-alerts publishes to it immediately. Update your subscription to match, or you'll stop getting notified.
